
# Saffron & Steam Café
Deploy Link : https://saffron-steam-4kdh.vercel.app/

## Concept
A warm, handcrafted café website built to create appetite and comfort.

## Tech Stack
- React (Create React App)
- React Router
- CSS (Custom with variables)
- CSS Bootstrap

## Setup

1. Clone repo
2. Run:
   npm install
   npm start

## Design Decisions
- Earthy brown palette for warmth
- Clean menu alignment
- Mobile-first layout

## Limitations
- No backend (as per assignment requirement)
