☕ Saffron & Steam Café
Brand Concept & Personality

Type: Café
Name: Saffron & Steam
Location: Fraser Road, Mithapur, Patna

Saffron & Steam is a cosy neighbourhood café built inside a renovated old bookstore space in central Patna. It blends the warmth of handcrafted coffee with the comfort of slow afternoons and meaningful conversations.

The personality is warm, earthy, and inviting — never corporate. It feels like a place where you stay longer than planned.

Deploy Link : https://saffron-steam-4kdh.vercel.app/

## Concept
A warm, handcrafted café website built to create appetite and comfort.
